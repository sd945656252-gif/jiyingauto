# 极映桌面软件

这里保存极映桌面软件的安装包、版本说明和更新清单。开发源码在独立私有仓库中管理，本仓库不推送其源码或提交历史。安装软件本身仍包含运行所需的程序与制作规则。

## 下载与安装

正式发布后，可从本仓库的 Releases 下载 Windows x64 安装包。当前正在准备 0.6.0-alpha.4 开发预览草稿，尚未发布正式版本；草稿只供仓库维护者审阅。

安装版包含本地制作引擎、统一规则包和必要运行组件。模型及媒体服务须在软件“模型与接口”中配置，具体协议和能力以预检结果为准；安装包不包含用户密钥、账号、项目或个人媒体。

## 软件更新

软件启动后和运行期间自动检查本仓库的正式 Releases，也可在“软件更新”中手动检查。检查不会自动下载或强制安装；安装前先保存草稿、暂停本地任务、确认后台退出并备份工程记录。

一次完整更新需要同版本的三个文件：

- `jiying-desktop-setup-<版本>.exe`
- 同名 `.exe.blockmap`
- `latest.yml`

只有高于当前版本、正式发布且未标记 prerelease 的 Release 才进入客户端更新通道。推送代码、创建标签、上传草稿或发布预览版均不会触发正式更新。没有更新器或仍指向旧仓库的预览版需先手动安装使用新地址的版本。

## 当前预览边界

当前包尚未配置发布者代码签名，FFmpeg 再分发及对应源码义务仍待核实，因此保持草稿。更新清单哈希检查不能替代发布者签名。尚未完成真实 GitHub 已安装旧版覆盖升级及完整生产素材出片验收，不将本地测试当作这些能力的证明。
